# Automation Workflow

1. Confirm the intended trigger, action, destination, and failure behavior.
2. Prefer deterministic tools over simulated UI input.
3. Preview state-changing actions and use the confirmation gate.
4. Verify the resulting file, process, reminder, or application state.
5. Make recurring work observable and easy to disable.
