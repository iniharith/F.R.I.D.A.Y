# Coding Workflow

1. Inspect the smallest relevant set of files before editing.
2. State the concrete failure or behavior being changed.
3. Make the smallest correct edit and preserve unrelated work.
4. Run the narrowest useful test, then the broader suite when practical.
5. Report what changed, what was verified, and any remaining limitation.

Never claim a command or test passed without a successful tool result.
